## ✨ 核心特性一览

### 1. 🪟 通透磨砂玻璃美学视觉 (Frosted Acrylic Glassmorphism)
* **无边框纯净设计**：彻底剥离 Windows 传统原生厚重边框与白条，通透磨砂与桌面壁纸浑然一体。
* **高分屏全矢量排版优化**：全局注入硬件加速字体平滑与抗锯齿渲染，杜绝任何生僻字黑块或边缘毛刺。
* **9 大经典护眼背景与自定义壁纸**：
  * `系统磨砂 (Frosted Glass)`：跟随系统全局透明度与毛玻璃质感
  * `羊皮古纸 (Parchment)`：古典暖黄做旧纸质感
  * `素雅宣纸 (Rice Paper)`：温润如玉柔和淡雅米白
  * `豆沙护眼绿 (Eyecare Green)`：舒缓眼疲劳经典豆沙绿
  * `暖阳燕麦 (Warm Latte)`：柔和温馨暖调奶茶色
  * `莫兰迪雅灰 (Slate Gray)`：高级低饱和暗夜雅灰
  * `复古牛皮纸 (Kraft Wood)`：沉稳厚重经典牛皮纸质
  * `幽夜深海蓝 (Navy Night)`：宁静沉浸深邃暗夜蓝
  * `纯黑 OLED (Pure Black)`：极致纯黑省电低光模式
  * **自定义背景**：支持自由上传本地任意图片作为阅读器背景，支持调节模糊度与透明度。

---

### 2. 📖 「连续瀑布流滚动 ⇋ 仿真左右翻页」双阅读引擎
* **📜 连续瀑布流滚动模式**：
  * 传统竖向连续滚动，支持 `Space 空格键` 启动/暂停平滑自动向下匀速滚屏，支持 1~5 档调速。
* **📖 仿真左右单页翻页模式**：
  * **智能分页算法**：根据当前字号与窗口动态排版分页。
  * **大面积触控与点击热区**：点击屏幕左侧 20% 上一页，点击右侧 20% 下一页，点击中间呼出控制中心。
  * **全套快捷键极速翻页**：支持 `D / → / Space / PageDown` 翻下一页，`A / ← / PageUp` 翻上一页。
  * **无缝跨章翻页**：翻至当前章节末尾继续翻页时，自动平滑翻入下一章第一页。
  * **精准进度记忆**：滚动位置与翻页页码实时持久化存储，下次打开精确恢复上次阅读位置。

---

### 3. 📚 小说与漫画全格式畅读 (Universal Format Engine)
* **电子书格式**：完整支持 **TXT**（智能分章匹配与编码自适应）、**EPUB**（富文本章节解析）、**Markdown (`.md`)**。
* **漫画图集支持**：支持直接拖入 **ZIP / CBZ / CBR 漫画压缩包**，自动提取图片并按自然文件名序号排序，以 **高清画卷连续流 (Webtoon Scroll)** 呈现，封面自动提取第一页。

---

### 4. 🛡️ 10 大办公全场景摸鱼变身伪装矩阵
内置专为职场打造的摸鱼变身系统，支持全局快捷键秒切：
* **📊 Excel 统计表模式** (`Alt + E`)：仿真工作簿界面，带公式编辑栏与多 Sheet 标签切换，正文伪装为表格单元格数据。
* **📝 Word 商务公文模式** (`Alt + W`)：仿 Office 经典公文排版与顶栏 Ribbon 工具条。
* **📧 Outlook 商务邮件模式** (`Alt + O`)：仿 Outlook 邮件客户端，收件箱列表与邮件正文阅读。
* **💬 办公即时通讯聊天模式** (`Alt + C`)：仿企业微信 / 钉钉群聊消息气泡流。
* **💻 VS Code 编辑器模式** (`Alt + V`)：深色代码高亮编辑器界面，带资源管理器树与面包屑。
* **💡 IntelliJ IDEA 模式** (`Alt + I`)：Java/Kotlin 经典工程 IDE 界面。
* **📽️ PowerPoint 幻灯片模式** (`Alt + P`)：PPT 演示文稿汇报视图。
* **📌 桌面便利贴模式** (`Alt + N`)：黄色便签纸极简小贴片。
* **📈 24px 底部极窄状态条** (`Alt + T`)：贴合屏幕底部的单行股票/监控行情走马灯。
* **👻 0ms 老板键瞬时隐形** (`Alt + \``)：瞬间抹除窗口并从任务栏消失，再次按下瞬时唤回。

---

### 5. 📱 智能窄窗口与小窗自适应折叠布局
* **智能多书切换胶囊**：当窗口拉至极窄状态（如 300px 便签模式）时，顶栏横向标签自动折叠为 `📖 [书名] (N) ▾` 胶囊，点击弹出毛玻璃下拉列表随意切换或关闭书籍。
* **控制中心自适应矩阵**：窄屏下导航栏自适应切换为 4 + 3 网格卡片，所有功能一览无余，绝不截断。

---

### 6. 🌐 Legado 3.0 书源全兼容与聚合搜书
* **全网多源异步并发搜索**：输入小说书名或作者，跨多个书源并发检索，实时聚合最新章节。
* **书源管理**：支持一键导入网络书源 URL / 本地书源 JSON 文件，支持书源分组、单源启用/禁用与批量删除。

## ⌨️ 核心效率快捷键速查表

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Alt + \`` | **0ms 老板键**：瞬时完全隐形 / 唤回窗口 |
| `Alt + M` | 打开 / 收起 **控制中心** (书架/目录/书签/搜书/设置) |
| `Space 空格` | 翻页模式下**翻向下一页**；滚动模式下**开启/暂停自动滚屏** |
| `D` 或 `→` 或 `PageDown` | 翻向**下一页** |
| `A` 或 `←` 或 `PageUp` | 翻向**上一页** |
| `]` 或 `J` | 快速跳转至**下一章** |
| `[` 或 `K` | 快速跳转至**上一章** |
| `Ctrl + +` / `Ctrl + -` | 快速放大 / 缩小阅读字体大小 |
| `Ctrl + F` | 唤起章节内**全文关键词搜索条** |
| `Alt + E / W / O / C / V...` | 快速变身为对应 **办公摸鱼伪装模式** |
| `拖住顶栏空白处` | 任意在桌面上移动小窗位置 |

## 🛠️ 本地开发与贡献

本项目基于 **Tauri 2.0 + React 18 + TypeScript + Vite + Tailwind CSS** 构建。

### 环境依赖
- [Node.js](https://nodejs.org/) (v18+)
- [Rust & Cargo](https://www.rust-lang.org/)
- Windows C++ Build Tools (针对 Windows 桌面编译)

### 开发命令
```bash
# 1. 克隆代码仓库
git clone https://github.com/Hyperion-WB/reader.git
cd reader

# 2. 安装前端依赖
npm install

# 3. 启动 Vite 开发服务器 (支持浏览器热重载预览)
npm run dev

# 4. 启动 Tauri 桌面应用进行调试
npm run tauri dev
```

## 📦 自动打包与 Release 发布

本项目已配置完善的 **GitHub Actions CI/CD** 自动化打包流水线：
- 代码推送至 `main` 分支或打上版本 Tag（如 `v1.0.6`）后，GitHub Actions 将在云端全自动编译生成 Windows 绿色免安装版与安装向导包 (`.msi` / `.exe`)。
- 打包产物将自动发布在仓库的 [Releases](https://github.com/Hyperion-WB/reader/releases) 页面供直接下载使用。
