## ✨ 核心特性一览

### 1. 🪟 通透磨砂玻璃美学视觉 (Frosted Acrylic Glassmorphism)
* **无边框纯净设计**：彻底剥离 Windows 传统原生白条/黑条边框，通透磨砂融于桌面。
* **六大温润护眼主题调色盘**：
  * `暗夜深邃 (Obsidian OLED)`：极深黑曜石磨砂 + 纯白高对比字体 + 苹果电光蓝点缀
  * `昼间通透 (Pearl Frosted)`：珍珠白磨砂玻璃，清晰高雅
  * `暖木羊皮 (Warm Parchment)`：柔和拿铁暖木护眼奶油色，长时间阅读不疲劳
  * `幽夜墨绿 (Forest Mist)`：雾霭松针绿底色 + 翡翠微光，夜间温润养眼
  * `赛博黑客 (Hacker Green)`：极客矩阵荧光绿终端风
  * `极致隐形 (Stealth Ghost)`：背景纯透、微灰文字，极致低调

### 2. ⚡ 苹果级灵动 Tab 与物理动效 (Apple-Grade Fluid Motion)
* **弹性胶囊 Tab 栏**：基于物理弹簧减速阻尼模型（`cubic-bezier(0.2, 0.9, 0.1, 1)`），切换书籍时指示器产生弹性拉伸滑行。
* **章节平滑淡入（Chapter Fade In）**：翻页与跳章时正文轻柔淡入浮现。
* **动态响应式两行 HUD**：小窗下自动折叠为双行圆角微型胶囊，大窗下展开为单行灵动岛，全窗口尺寸永远 100% 绝对水平居中。

### 3. 🌐 自定义书源与全网聚合搜书 (Book Source Engine)
* **Legado 3.0 / 开源阅读规则全兼容**：支持导入网络或本地书源 JSON / URL 链接，支持 CSS 选择器、XPath 与正则解析。
* **全网多源异步并发搜索**：输入小说名或作者，跨多个书源并发检索，实时呈现最新章节。
* **本地多格式解析**：
  * **TXT 智能分章**：自动识别汉字/阿拉伯数字章节正则，自适应 GBK/UTF-8 编码。
  * **EPUB 深度解析**：自动解析 Spine 目录与章节富文本。

### 4. 🎭 五大办公多维伪装矩阵 (Stealth & Chameleon Suite)
* **0ms 极速老板键 (`Alt + \``)**：瞬间抹除窗口，后台零开销静默，再次按下原位复原。
* **Excel 电子表格模式 (`Alt + E`)**：窗口瞬间化身为 Microsoft Excel 表格，小说内容融入单元格与公式栏。
* **VS Code 代码编辑器模式 (`Alt + C`)**：化身为暗黑代码编辑器，小说内容伪装为代码注释 `// ...`。
* **IntelliJ IDEA 伪装模式 (`Alt + I`)**：高保真 JetBrains Darcula 界面，小说藏入 `@Slf4j log.info(...)`。
* **Win11 便签备忘录模式**：伪装成系统黄色桌面便利贴。
* **24px 极简单行状态条 (`Alt + 1`)**：收缩为 24px 系统微型状态条，单行跑马灯微速滚动。

### 5. 📖 高阶小说阅读器功能全景
* **自动平滑滚屏摸鱼（Space 快捷开启）**：1x ~ 5x 速度档位悬浮调节，鼠标触碰智能暂停，章节末尾自动切章。
* **万章级高性能虚拟滚动目录（Virtualized TOC）**：支持 10,000+ 章长篇玄幻小说 120 FPS 丝滑滚动，支持百章分卷快速直达与一键定位当前阅读章节。
* **章节内全文实时搜索（Ctrl + F）**：黄色高亮徽标定位，Enter / Shift+Enter 快速跳转。
* **书签与读书笔记管理**：划词即刻添加精选书签，支持一键导出为标准 **Markdown (.md)** 笔记文件。
* **多风格书架排版**：支持紧凑列表（List）、极简纯文本（Minimal）、精美网格大卡片（Grid）三模式切换。
* **低调隐蔽封面定制**：支持一键替换为商务深灰、曜黑、暖木、墨绿等纯色隐蔽书皮，或根据书名智能检索网络封面。
* **静默 TTS 听书与数据备份**：集成自然语音朗读，支持书架/进度/书源全量 JSON 备份与还原。

## 🚀 GitHub Actions 自动云端打包与发布

本项目已配置完整的 GitHub Actions 自动化编译工作流（`.github/workflows/release.yml`）。无需在本地搭建复杂环境，直接推送至 GitHub 仓库即可由云端全自动编译：

1. **推送最新代码**：
   ```bash
   git add .
   git commit -m "feat: release LiquidReader v1.0.0"
   git branch -M main
   git push -u origin main
   ```
2. **触发发布打包**：
   * 打上版本 Tag 并推送：
     ```bash
     git tag v1.0.0
     git push origin v1.0.0
     ```
   * 或者进入 GitHub 仓库页面点击 **Actions** -> **Release Build** -> **Run workflow** 手动触发构建。
3. **获取安装程序**：
   * GitHub Actions 编译完成后，将自动在仓库的 **Releases** 页面发布 Windows `.exe` 安装程序与便携版绿色包！
